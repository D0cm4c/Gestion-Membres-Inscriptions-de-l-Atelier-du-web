        Mot de passe admin

        Actions sensibles de l'app

        Le mot de passe admin protège la page Paramètres, la suppression de membres, l'import XML et la purge des données. ⚠️ Le mot de passe par défaut est admin — change-le dès maintenant. Il est stocké haché (SHA-256) dans ce navigateur uniquement.

        Données personnelles (RGPD)

        Base SQLite locale à ce navigateur

        Les données des membres et inscrits sont stockées dans ce navigateur (base SQLite locale). Les données du site atelierduweb.be (formations, salles) sont conservées.

        • Effacer un membre — depuis sa fiche ou la liste : supprime aussi ses visites, impressions et inscriptions.
        • Purge complète — efface tous les membres, visites, impressions, inscriptions, réservations en attente et suggestions. Irréversible.
