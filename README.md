# Gestion des Membres et Inscriptions - Atelier du Web

Un système unifié pour gérer les membres du cyberespace et les participants aux formations de l'[Atelier du Web](https://atelierduweb.be).

## 📌 À propos

Ce projet permet de :
- Gérer les **membres** du cyberespace.
- Gérer les **inscriptions aux formations** proposées par l'Atelier du Web.
- Centraliser les informations dans des **fiches membres/participants**.

## 🚀 Démarrage rapide

### Prérequis
- Un navigateur web moderne (Chrome, Firefox, Edge, etc.).

### Installation
1. Clonez ce dépôt :
   ```bash
   git clone https://github.com/D0cm4c/Gestion-Membres-Inscriptions-de-l-Atelier-du-web.git
   ```
2. Ouvrez le fichier `index.html` dans votre navigateur.

## 📂 Structure du projet

```
Gestion-Membres-Inscriptions-de-l-Atelier-du-web/
├── index.html              # Tableau de bord (accueil)
├── membres.html            # Gestion des membres
├── app.js                   # Logique (CRUD membres, localStorage)
├── styles.css               # Styles CSS
├── assets/                  # Images (logo, etc.)
└── README.md                # Documentation
```

## 🎨 Maquettes

- [Tableau de bord (Dashboard)](index.html) : Vue d'ensemble des statistiques, alertes et prochaines formations.
- [Membres](membres.html) : Fiches membres, ajout/modification via formulaire, recherche.
